# Patent
## Приложение подразумевает систему *автоматической* выдачи патентных прав на базе ИИ.
# Задачи
### В система будет выполнять задачи, такие как:
- Автоматический прием документов от заявителя;
- Автоматическая обработка и нахождение похожих патентов;
- Автоматическое выявление ошибок и несостыковок в документах;
- Полуавтоматическая выдача патентных прав;
- Локальный ИИ и локальная инфраструктура развертывания на базе железа пользоваьтеля;
# Стек разработки
### В системе будут использоваться такие средства разработки как:
- **Веб-ядро**: ASP.NET core;
- **База данных**: MS sql;
- **Фреймворк**: Razor pages;
# Преимущества системы
Данной системе по сути своей нет аналогов, большинство из похожих на нее либо не очень безопасны т.к. находятся на облаке разработчиков, из-за этого есть вероятность утечек либо слишком закрыты из-за этого усложняется возможность расширения на другие бюро патентных прав. К тому же большинство систем не используют ИИ или используют, но только облачный.
### Кратко об приемуществах:
- *Используется локальный ИИ*;
- *Инфраструктура разворачивается локально на железе пользователя*;
- *Открытая к изменениям заказчика и масштабируема*;
